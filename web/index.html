FastAPI + LangGraph Supervisor

안녕하세요. 차량 매뉴얼, 정비이력, 근처 정비소 관련 질문을 도와드릴 수 있습니다. 차량번호나 궁금한 증상을 말씀해 주세요.

동작 방식 · FAQ

동작 방식

  1. 01

    질문을 Supervisor 에이전트가 받아, 매뉴얼 검색·정비이력·정비소 조회 중 담당 에이전트에게 위임합니다.

  2. 02

    담당 에이전트가 실제 도구(RAG 검색, SQLite 조회, 지역 검색)를 호출해 근거를 확인합니다.

  3. 03

    근거가 없으면 지어내지 않고, 확인되지 않는 정보라고 그대로 안내합니다.

example — POST /query 응답 200 OK 
{
  "answer": "…",
  "contexts": ["…"],
  "trace": [
    { "type": "agent", "name": "maintenance_agent" }
  ]
}

자주 묻는 질문

차종이 다른 차를 여러 대 갖고 있으면 어떻게 되나요?

이전에 확인한 차종을 다른 질문에 그대로 적용하지 않습니다. 지금 질문에서 차종이 확인되지 않으면 다시 물어봅니다.

정비이력을 삭제하거나 수정하면 바로 반영되나요?

되돌리기 어려운 변경이라, 먼저 한 번 더 확인을 요청한 뒤에만 실행합니다.

매뉴얼에 없는 내용을 물어보면요?

지어내지 않고 확인할 수 없는 정보라고 안내합니다.

API를 직접 호출할 수도 있나요?

POST /query는 answer·contexts·trace를 한 번에, POST /query/stream은 같은 내용을 토큰 단위 SSE로 스트리밍합니다.
